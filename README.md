# CreatorOS

CreatorOS is a starter monorepo scaffold for building an AI-enabled product platform.

## Structure

- docs/ — project documentation and architecture notes
- frontend/ — web client application
- backend/ — API services and business logic
- ai/ — model, prompt, and inference workflows
- infrastructure/ — deployment and cloud infrastructure assets
- scripts/ — automation and maintenance utilities
- assets/ — static design and media files
- storage/ — local data and persisted artifacts
- .github/ — GitHub workflows and automation

## Getting Started

1. Review the docs and environment example.
2. Configure your environment variables from .env.example.
3. Start local dependencies with Docker Compose.

```bash
docker compose up -d
```
